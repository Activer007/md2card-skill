审查核对了参数白名单及中文别名、单卡优先级、默认输出保持、嵌套列表只缩放一次、

屏幕/打印溢出拒绝和 manifest 档位记录。未发现阻塞问题。

没有重写旧 PNG/PDF、放松原始证据哈希或给非默认档继承视觉验收。
