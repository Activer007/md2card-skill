## 执行顺序

1. 固定输入契约与回归测试，先保证旧 Markdown 可用。
2. 添加诊断、资源上限、结构化错误与可追溯 manifest。
3. 抽离布局，接入本地图片与品牌，不引入任意 HTML/CSS。
4. 增加预览、联系表与三套原创示例。
5. CI 必须具备 Chromium、中文字体、pdfinfo、pdftotext；实际导出八版式 × 五主题，检查失败路径。
6. 查看真实输出，修复发现的问题；将选定 PNG 作为 README 展示图片，记录对应源命令和提交。
