## 生成与单一来源

```bash
npm run gallery:build
npm run gallery:check
npm run test:gallery
```

等价入口为 `node scripts/build-template-gallery.mjs` 及其 `--check` 选项。这些生成/源检查仅使用 Node.js 内置模块与注册表，不导入渲染器、不启动浏览器、不请求网络。注册表、示例、证据绑定或生成器改变后须重新生成索引；`--check` 检查已签入输出是否一致。

唯一模板集合来自 [scripts/templates.mjs](../scripts/templates.mjs)。名称、家族、用途、图片需求、示例密度、内容结构、限制、版本、来源与输入路径来自该注册表。家族中文名只是显示标签，不是第二套模板清单。

[证据绑定](template-gallery-evidence.json) 固定各验收批次的文档与机器来源文件 SHA-256，并约束具体版本、密度和画幅。新批次须先完成独立产物复核，再明确绑定。SHA-256 证明文件一致，不代替视觉判断。原始机器记录中的 `rendered-not-visually-reviewed` / `not-performed` 是自动采集阶段状态，最终独立结论另载于验收文档；不得回写原始报告伪装机器曾完成目视审查。

构建拒绝缺失/重复/孤立记录、未知验收批次、状态或版本/密度/画幅不匹配、错误示例路径/元数据、缺失或哈希不符的 PNG/输入/证据，以及非法 PNG 尺寸/来源哈希、不安全路径、逃逸符号链接、非普通文件和失效资源。验收文档必须含对应批次、精确提交、真实 PNG 与原始输入。更新哈希前先复核变更，不能自动刷新绑定掩盖失败。

## 界面与筛选含义

- 分别统计源码已实现、已验收、待验收与家族数。已实现减去已验收得到待验收数；换色、品牌和画幅不增加模板数。
- 只有带有效验收绑定的原始 PNG 才能作为预览，保持原比例，不用色板、概念图、CSS 草图或其他模板图片代替。没有绑定的设计仅展示文字契约与示例链接。
- 家族、图片需求和注册示例密度为精确条件；用途字段按 ID、名称、用途进行 NFKC 规范化、不区分大小写的子串检索。各条件取交集，不把输入作为正则表达式。
- “注册示例密度”不是全部已支持密度的验收列表。standard 截图不能证明 compact/editorial。密度控制间距，不能用于偷偷缩小正文。
- 筛选状态只存在于当前页面内存，不保存、不请求网络、不改输入或链接。计数报告已验收/待验收命中数，重置清空条件。
- 无脚本时完整静态索引、原生 details、原 PNG、输入及证据链接仍可访问；筛选控件只在脚本成功初始化后出现。
- 画幅标签来自支持契约，不是额外模板或预览。portrait 证据不能作为 square/slide 验收，八个额外画幅组合的当前 pending 范围见 [独立画幅](TEMPLATE_ASPECTS.md)。

离线使用时保留仓库目录结构，不要单独复制 HTML。图库使用本地经典脚本，不依赖在 file:// 下可能触发模块 CORS 的 module/fetch。当前真实证据仅针对记录的 Chromium 环境，不保证所有浏览器行为相同。

## 安全与可访问性边界

图库独立 CSP 默认全部拒绝，仅允许同源本地脚本、样式和图片。网络连接、字体加载、表单提交、嵌入对象与 base URL 被禁止；无内联脚本/样式、事件处理器、eval、用户 HTML 或 DOM HTML 注入。字段按文本/属性位置转义，路径有白名单和真实路径检查；筛选只读 dataset，用 `hidden` / `textContent` 更新。这不改变渲染器或导出文档的 CSP。

历史 v1 真实检查覆盖原生 label、键盘 Tab/Shift+Tab、可见焦点、跳过导航与 details 开关，以及手机/重排读序和无脚本回退。代码还包含实时计数和强制颜色支持，但这些实现不等于屏幕阅读器、完整对比度审计或可访问性认证。

**历史 v1 已测等效 200% reflow，未测原生浏览器菜单 200% 缩放；当前 M2 新绑定页面仍待复核。** 等效法将 1280×900 CSS 视口改为 640×450，不是 pinch zoom，也不通过改变字体/样式放宽检查。辅助技术读屏播报和跨浏览器兼容性仍未验证。

## 真实 gate 的复现与输出

仅在允许启动 Chromium 的环境使用：

```bash
npm run validate:gallery -- --allow-browser --out validation/gallery
```

`--allow-browser` 是防误触门槛，不是越过用户或环境限制的授权。脚本不安装浏览器、不使用关闭沙箱/安全的参数、不改 CSP，也不触发 Actions；输出目录必须为空或不存在。

真实 gate 检查本地 file:// 资源/CSP/JS/PNG 尺寸、页面请求精确白名单、全部筛选/组合/空状态/重复操作/重置、键盘顺序、禁用 JS、1280px 桌面、375/390px 手机和等效 200% reflow。折叠及展开详情后检查页面与后代横向溢出。它监测页面请求，不宣称监测浏览器进程所有后台流量。

截图记录索引、真实预览区域、候选目录和展开详情等视口范围，不是每个条目每个像素的整页覆盖。`summary.json` 保留检查结果、请求/错误、浏览器版本、输入/验证脚本哈希、截图尺寸/哈希/范围与清理结果。每个 evaluate/evaluateAll（含 image.decode）有 15 秒上限，失败聚合，不因一个视口失败跳过其余检查。启动拒绝不重试，异常保留报告并清理。

源测试覆盖参数门槛、证据完整性、路径/XSS、筛选语义、空状态、稳定生成、超时、清理、失败聚合与输出保护。它们不能替代真实运行，真实脚本也不能替代独立视觉复核。发布后的资源或索引改变时，须按实际影响重新检查，不能复用旧结论扩大范围。

## R10：任务优先与同文对照

入口新增六条任务路线：解释概念、有条件比较、引文与理解、步骤清单、图片叙事、主张与指标。它们只是指向唯一 48 套注册表的静态导航，不制造新设计或默认推荐已通过的假象；每个链接标明当前版本有无有效预览。

同文对照固定三组原始输入（短篇、中篇、中英混排），各选四个有意义的模板。正文哈希必须一致，生成时只改变模板元数据。`docs/gallery-comparisons.json` 把待验收计划与 `reviewed-exact-fixtures` 明确分开：后者必须绑定当前模板版本、standard / portrait / manual 范围、代码提交/树、Actions 产物包、逐图复核文档、原始 PNG/PDF 哈希及精确图片路径。合成单元测试只测试校验分支，绝不成为生产证据。

当前三组均为 pending，界面只有同文输入链接，不插入旧版或不同文案缩略图。将来通过复核后的同文图放在独立 comparison 目录；不会替代注册示例、改变已验收模板数，或扩大为所有内容验收。详见 [真实内容矩阵](CONTENT_MATRIX.md)。新导航、同文区域及当前 v3 / v2 页面仍待实际 file://、手机与键盘复验；历史图库检查不能自动继承为本轮通过。

T13 的指定中篇不是短宣言海报的适用输入：对照必须显示完整原文的明确拒绝与选型建议，不伪造第四张图，也不计为成功适配。拒绝证据同时绑定受控元数据、完整正文生成的输入字节、输入文件名与哈希、同名溢出诊断及精确版本；声明正文哈希正确不能替代实际输入身份。

任务或同文链接指向被筛选隐藏的模板时，会先重置筛选再沿原生锚点跳转；键盘 Enter 保持相同行为。无脚本时所有条目本来都显示，不依赖这一增强。
