## 最小引擎变化

仅为 T21 增加注册表支持字段及必填字段。已有白名单中的 metric / label 在该模板中经 plainText 转义，放在标题之后、正文之前；其他模板继续明确拒绝这些不会显示的字段，避免信息丢失。没有开放任意元数据、HTML/CSS 或路径。

未选择模板的 statistic 行为不变；不改变 manual、显式分隔、auto 支持范围、安全资源解析或测量预算。长内容验证使用每套示例的合法元数据配合合成长段落，确保是在测容量拒绝，而不是误测缺字段错误。
