## 八种构图

| ID | 信息组织 | 图片契约 |
| --- | --- | --- |
| T33 | 居中报头、导语、双栏目 | 纯文字，原创虚构周刊，不冒充新闻 |
| T34 | 专栏主文与资料侧记 | 纯文字；后续节全宽保留 |
| T37 | 大图先行、底部标题与信息带 | 必须有本地元数据 image；完整 contain，不裁切 |
| T38 | 两帧错位接触印样与逐帧观察 | 恰好两个 H2 图像记录，各一个本地 Markdown 图片；错配明确拒绝 |
| T41 | 问题标题气泡、回答和边界色块 | 纯文字问答；不新增原文没有的结论 |
| T42 | 贴纸编号步骤 | 原始编号 0–99；超出明确拒绝，不重编号 |
| T45 | 植物插画边栏与留白笔记 | 必须有本地 image；示例不是植物鉴定依据 |
| T46 | 材质图、两组观察说明 | 必须有本地 image；示例不是产品性能测试 |

这些布局有不同的读序与区域组织，不把配色、字体或图片替换计为新模板。主题图片默认保全全幅；本批没有添加裁切或远程图片能力。

## 原创图像与出处

新增三份示例资产：窗边静物（1536×1024）、完全虚构的成年陶艺创作者（1024×1536）、透明橄榄枝插画（1024×1536）。三者均为原创 AI 生成素材，不是现场照片、真实人物采访、既有植物图谱或参考网站截图。

每份的生成性质、尺寸与 SHA-256 位于 `examples/templates/assets/provenance.json`，说明位于同目录 `README.md`。相关模板注册表不再错误继承“无素材”的描述；图片 alt、图注和来源保留合成/虚构披露。MIT 授权范围和 AI 输出不主张独占版权的说明随资产一起提交。

## 最小契约扩展与测试

- required 图片模板缺字段、空路径或缺少已验证资产时明确报 `TEMPLATE_IMAGE_REQUIRED`。
- inline 图像模板拒绝不会显示的独立 image/alt/caption 元数据；T38 数量与每节对应关系不符时分别报 `TEMPLATE_IMAGE_COUNT` / `TEMPLATE_IMAGE_STRUCTURE`。
- 纯文字模板同时拒绝内联图和直接传入的已解析图片，不会悄悄显示或丢弃它们。
- 继续使用已有 PNG/JPEG/WebP 可信路径、解码检查、累计嵌入/像素预算；不改变资源权限或自动分页。
- 超长压力输入追加在完整示例之后，保留必需图像与元数据，避免把结构缺项误当容量检查。
