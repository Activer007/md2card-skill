## 已验证

`npm run test:unit`：169/169 通过，0 跳过。新增 T24 真实 3×3 表体与表头保全、列宽和正文字级源规则；T20 图片/图注/来源身份和实际尺寸；T28 原始 start=7；T31 硬换行；额外列表与引用的源码保全和网格轨道约束。

全部示例的 token 派生分区仍能完整拼回原 parser HTML。默认颜色静态检查不等于真实对比与可读性验收，自定义品牌色仍需另查。

## 待验收

获准环境中运行 `npm run validate:templates` 后逐张看 PNG、375/390 实际内卡与原生文本 PDF。重点：T20 图片与功能区总高、T24 狭窄表格单元格、T27 长日期和附加块、T31 引句与印记间距、T32 书页窄栏。脚本不能仅因字号够大就宣布文字读起来舒服。

Actions 仍关闭，本批没有真实卡片缩略图，也没有新模板视觉通过声明。长表、长代码、长标签等不适用输入必须完整保留并明确失败，不靠删改或缩字过关。
