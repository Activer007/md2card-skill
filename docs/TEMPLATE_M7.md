## 最小结构能力

T39/T40 的 figure-before-main 开关只来自冻结的仓库注册表。输入不能传入顺序字段，图片仍仅调用既有安全 figure helper 一次。其他模板顺序不变。

图文记录校验保留所有源内容，遇到数量/对应关系不符明确拒绝。T43/T47/T48 要求图片是独立、未包裹链接的 Markdown 图片段落，不能与正文混在同一段；这种输入不适用时不尝试用正则拆文。解释段落、列表和引用仍完整保留。T48 第三节及以后可保留无图限制。

T44 同级引用块与独立图片段落的形状由安全解析器 tokens 得出，不用 HTML 标签数量猜嵌套语义。元数据白名单、图片 resolver、安全预算、manual 和 auto 支持范围不扩大。选项标签是否语义一致、图注是否如实描述素材，仍需内容审查，不能用结构测试冒充理解。

## 内容与素材来源

八张新 PNG 为从空白画布绘制的原创程序图形，可由 `scripts/create-template-art.py` 在空目录重建，已逐一验证重建后的 SHA-256 完全一致。完整尺寸、来源与许可见统一资产 provenance；不读取、裁切或复制第三方艺术。T39 复用未修改的虚构成年肖像。

T36 原创概括所用 NASA 页面和核实范围见 `template-source-references.json`。其余示例明确原创/虚构/未实测，不冒充真实采访、产品数据或科研结果。
