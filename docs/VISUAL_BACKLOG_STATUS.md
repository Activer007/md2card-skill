## 不变的保全与安全边界

- 默认 manual，不自动增加封面、总结或行动承诺。auto 仍仅 explainer/steps 和 layout 元数据；`--balance-tail` 必须显式开启。
- `===` 锁定；不改写原文、不删出处/单位/限定条件、不拆原子块、不缩字、不隐藏内容溢出。
- 图片仍走本地 raster resolver 与原有资源/像素/输出预算；模板不能插入任意 CSS/HTML/路径。固定装饰编号有明确边界，不能偷改列表起点。
- 所有示例保持原创/虚构/未实测或真实资料来源说明。图片输入、程序测试图案和概念设计不是实际模板预览。
- 不新增账号、同步、模型调用、部署或 PPTX。授权环境的真实测试、独立源码审查与逐图检查各自记录，互不替代。

## 验证入口

源码：`npm run test:unit`、`npm run gallery:check`；压力案例的 `--plan` 明确不运行浏览器。

真实验证在获准环境运行现有只读 workflow。各导出套件只在必需测试通过后开始，并分别汇总：旧 showcase、原 semantic pagination、tail、48 模板与长文/同文、series、visual-stress、gallery、aspects。上传 `validation/` 的成功和失败证据；失败不可改成跳过或静默接受。

新真实出图被检查并确认以前，本页以及 CLI/图库状态均保持待验收。实际浏览器菜单 200% 缩放、辅助技术的完整读屏检查仍是图库自动等效 reflow 之外的明确边界。
