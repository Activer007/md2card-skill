三条耗时为 120、180、150 毫秒；本例只求
它们的算术平均值。
运行：逐项累加
 const ms = [120, 180, 150];
 let sum = 0;
 for (const n of ms) sum += n;
 console.log(sum / ms.length);

结果：输出 150
分母为 3 条记录。结果不是实际性能测量，也
不代表更大的样本。
