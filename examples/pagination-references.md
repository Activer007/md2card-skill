# ZONE_B 检查 / Check

REF_B01 ZONE_B: The [reading guide][guide] is shared with the preceding partition. Reference definitions are document context; sharing a definition must not merge the two source partitions.

REF_B02 ZONE_B: 核对完整内容，而不仅是页数。A result with the expected number of pages can still be wrong if a paragraph is missing, an item is duplicated, or a destination changes.

REF_B03 ZONE_B: Use [the review checklist][review] for a second pass. Its definition is later in the document, and its title should survive the transformation without being rewritten.

REF_B04 ZONE_B: Searchable text provides another independent check. The exported PDF should contain every unique record marker, and each marker should appear on exactly one page.

REF_B05 ZONE_B: 手动边界是明确约束。The next partition starts a new card, not a new paragraph underneath the remaining material from this checking section.
