# 纸本，还是数字

先想下次怎样用笔记，再选择载体。这里比较的是记录需要，不是工具排名。

## 留在纸上

想随手画关系、翻看一页的整体，可以从纸本开始；仍要约定存放位置。

## 留在文件里

需要检索词语或持续修订，可以试用数字文件；先确认格式能否导出，不把保存等同于备份。

# 把条件摆在前面

同一个人，不同任务也可以换一种方式。

## 三个检查点

| 码 | 当前需要 | 选择前核对 |
| --- | --- | --- |
| A | 看整页关系 | 能否自由画线 |
| B | 找特定词句 | 检索范围是否够 |
| C | 长期保留 | 怎样留存副本 |

## 不必一次定终身

先选最重要的一项，再接受其余取舍。没有哪种载体自动满足全部需要。

# 先试一条真实笔记

不急着迁走旧记录。用一个可撤回的小试验，检查选择是否适合自己。

1. **留一条记录**：选眼前的任务，不编造理想使用场景。
2. **隔天再找回**：记录从哪里找、卡在哪里，不把一次顺手当成定论。
3. **检查退出方式**：试着复制或导出，保留原件，再决定是否继续。
