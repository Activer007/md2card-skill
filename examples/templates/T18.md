# 算出一组耗时的平均值

先把耗时相加，再除以记录数。

## 运行：复制这段 JavaScript

```js
const ms = [120, 180, 150];
let sum = 0;
for (const n of ms) sum += n;
console.log(sum / ms.length);
```

## 检查：输出应为 150

示例均值是 150 毫秒。真实数据还需处理空数组，另查异常值。
